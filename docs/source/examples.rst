Examples
========

This section highlights practical scripts shipped with the repository.

Recommended showcase set
------------------------

- ``run_wind_demo.py``: full end-to-end workflow
- ``run_gpx_processor_demo.py``: GPX preprocessing focus
- ``run_wind_course_demo.py``: route simulation scenarios
- ``run_wind_equivalent_slope_check.py``: wind virtual slope analysis

Example execution
-----------------

.. code-block:: bash

   python run_wind_demo.py

Each example should describe:

- Required input files
- Main runtime parameters
- Key outputs to inspect
